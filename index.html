Test steps

How each UAT run is executed.

01

Prepare the environment

Set up the staging credentials, confirm the correct base URL, and ensure the EO and Vendor accounts are ready.

02

Launch the journey

Run the relevant Playwright flow for EO, Vendor, RFQ, or Event Service to begin the automated execution.

03

Validate each scenario

Every case checks the critical actions, expected screens, and validation states before marking Pass or Fail.

04

Report back to tracker

Results are written to the Excel tracker with the outcome, date, and any failure notes for quick UAT review.

Setup

Configure your staging credentials.

The suite expects valid EO and Vendor accounts on the staging platform. Create a local .env file from the example template and add your values. 

cp .env.example .env
# update EO_EMAIL, EO_PASSWORD, VENDOR_EMAIL, VENDOR_PASSWORD

Required values

  • EO account
  • Vendor account
  • Optional admin credentials
  • BASE_URL for staging

Run

Execute the suite from the terminal.

npm install
./run-uat.sh

# or run a single journey
./run-uat.sh eo
./run-uat.sh vendor
./run-uat.sh rfq
./run-uat.sh svc

What happens

  • Launches Playwright browsers
  • Runs the selected journey(s)
  • Exports JSON results
  • Updates the Excel tracker
